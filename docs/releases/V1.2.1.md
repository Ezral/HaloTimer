# HaloTimer 1.2.1

- Full-screen timers use the whole display and open with the header hidden.
- Pinch inward with two fingers to reveal the header; pinch outward to hide it. The header fades/slides above the timers without moving their geometry or resetting animation.
- Multi-touch gestures cannot activate timer controls. Ordinary taps remain available, plus a Show/Hide header accessibility action.
- Moving edge segments stay connected around the closed perimeter seam, with rounded ends. Active animation follows display frames without an extra frame delay; idle displays update less frequently.
- Physical corner radii, waterfall insets and manual edge adjustments remain supported.

Version 1.2.1 (11). Existing timer settings and signing identity are retained. Native regression checks exercise real two-pointer input, edge-to-edge bounds, fixed countdown placement, playback, completion, and seam continuity.
