# HaloTimer v1.0

The first named product milestone, built from the phone-tested alpha07 feature baseline.

Android version name: **1.0.0**. Version code: **8**.

This milestone retains the approved timer behavior and changes the app's version branding. The feature README and quick guide now describe the current solid pill, shallow dock, curved text, settings actions and completion screen rather than earlier glass-control prototypes.

## Included

- Three independent single timers or named sequences.
- Full-display edge progress and four continuous completion-light styles.
- Solid timer-colored pills and shallow edge docks with drag-contact morphing.
- Optional outside pill names, contour-following dock text and full-circle held text.
- Play/Pause, Reset, Stop and Settings in floating and dock controls.
- Double-tap or custom Morse haptics with count, duration or until-dismiss repeats.
- Configurable color-expansion completion page.
- Light, Dark and Follow system; reduced motion; optional local volume controls.
- Local persistence, deadline-based timing and silent notification controls.

See the [README](../../README.md) for the complete feature inventory and the [quick guide](../QUICK_START.md) for usage.

## Build and distribution

The downloadable APK remains development-signed under `com.ezral.halo.debug`, using the existing CI key for compatible in-place updates. Naming the milestone v1.0 does not change its signing identity or publish it to an app store. Production signing and wider device qualification remain separate tasks.

The feature baseline passed 42 JVM tests and Android 15 native checks for gestures, both settings routes, playback, parallel timers and completion behavior. Android lint reported zero errors. The v1.0 branding build runs through the existing Android workflow.
