# HaloTimer 1.3.1 — presets inside the sequence editor

Corrects the placement and scope of the preset feature from 1.3.0.

- Presets appear only in Sequence mode, directly above the editable steps.
- The fixed Pour-over and Steak buttons are replaced by the user's saved
  sequences. Each saved name is a selectable button with a replace confirmation.
- Save sequence stores the current step names, durations, hours setting and
  sequence repetitions. Manage presets provides load, rename, update and delete.
- Loading updates the sequence steps and repetitions. Timer name, colors, alerts,
  single-timer duration, placement and global preferences remain as configured.
  Hours is enabled when needed and is never disabled by loading a preset.
- The separate top-level preset card has been removed. Single mode has no preset
  controls; the engine also rejects single-timer save/load commands.
- Existing 1.3.0 sequence presets remain available. Old single-timer presets
  remain stored, but are excluded from the sequence choices and name checks.
- Existing timer data, running-session protection, organized preview section,
  full-screen controls and the diagonal-line fix are preserved.

Validation gates: core tests, lint, APK assembly, and the Android 15/16 native
workflow. Preset tests cover storage compatibility, sequence-only scope, focused
step-field saving, direct preset buttons, CRUD, live-session protection, and
preserving the destination timer's settings. Final results are recorded in the PR.
