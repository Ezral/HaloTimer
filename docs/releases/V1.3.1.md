# HaloTimer 1.3.1 — preset library polish

- Retains the whole-timer saved presets introduced in 1.3.0. The unmerged sequence-only proposal was dropped.
- Timer tabs always use two text rows: a single-line name and a status/countdown. Long names use an ellipsis and remain available to accessibility services. Starting or resetting a timer does not change tab height.
- Presets have a dedicated heading, save action, compact color-marked cards with duration and rounds, and a helpful empty state.
- Tap a card to confirm loading a preset. Browse opens a card-based library with a clear Load action and a menu for rename, update and delete.
- Keeps the existing menu and preview grouping. Saved data and preset behavior are unchanged.

The Android workflow checks core tests, lint, APK assembly and native UI regressions on Android 15 and 16. Native coverage includes consistent tab heights, direct card loading, preset CRUD/persistence and light/dark screenshots. See the pull request for completed results.
