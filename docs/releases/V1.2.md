# HaloTimer 1.2

- Repeat single timers or whole sequences: once, infinitely, or 1–9999 total rounds. Defaults remain once. Reset rewinds to round one, paused; Stop terminates the loop.
- The last palette circle recalls the saved custom color. Aurora, Sunset and Electric offer mixed-color edge lines with solid pill/dock accents.
- First typing into an hour, minute or second field replaces its old digits. Done or moving focus commits the edit.
- Full-screen display supports one, two or three selected active timers, including pizza-style three-way sections and landscape layouts. Playback remains independent. Switching display modes preserves sessions.
- Completion color expands and contracts within its timer section. Repeating rounds get a round-complete reveal; overlapping rapid round reveals are coalesced. Sound/vibration repeat settings remain separate.
- Full-screen Keep screen awake is opt-in. Overlay mode remains the default.

Existing timer data is read with once-only and solid-color defaults. Runtime loops use monotonic deadlines and bounded reconciliation after sleep, avoiding an unbounded alert backlog. Precise delivery remains subject to Android alarm and power-management constraints.

Validation: see the pull request's Android workflow for engine tests, lint, APK build and native editor/display regression results. Physical-device validation is still recommended for OEM-specific overlays and power behavior.
