# HaloTimer 1.3.0 — saved presets and menu organization

Status: release candidate. Build, lint and native test results are recorded in the pull request and linked Android workflow.
Based on 1.2.2 commit `33683289ccc7dc4cafb8c07372772527d2677a08` (PR #4).

## Saved presets

- Browse and Save current are directly above the timer editor, including long sequences.
- Save a named single timer or a whole sequence. Includes configured durations,
  step names, repetitions, colors/custom color, mixed palette, glow, edge alert,
  sound, vibration/Morse and repeat settings, and pill name/rotation settings.
- Load into the selected slot, rename, explicitly update from its current
  configuration, or delete. Load/update/delete have confirmation dialogs.
- Names are trimmed, limited to 40 Unicode code points, and unique without case.
- Presets are independent copies, persisted atomically in the existing Room
  checkpoint. Old checkpoints default to an empty library; no database migration
  is required. Stop/reset and changing a timer do not delete or update presets.
- Saving uses configured durations, not adjusted live remaining time. Loading
  requires a reset slot and never starts the timer. Slot identity, active/hidden
  state, docking and screen position are retained; other timers are unchanged.
- App-wide preferences (theme, completion display, full-screen layout and phone
  fit, volume controls, dock motion) stay global and are not captured in a preset.
- A save reports success only after the coordinator confirms successful execution.

## Menu

- Timer tabs → preset shortcuts → timer/sequence setup.
- Look & previews: display mode/selection and all preview entry points together,
  followed by edge light, floating pill/dock controls, and completion settings.
- Alerts: sound, vibration, Morse and alert repetition together.
- App settings: general controls, permissions and theme at the bottom.
- Smaller card padding/gaps; preview buttons wrap on narrow screens. The existing
  completion text sample can be expanded within the preview group.
- 1.2.2 perimeter graphics code and immersive/pinch controls are unchanged.
