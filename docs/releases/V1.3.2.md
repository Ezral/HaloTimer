# HaloTimer 1.3.2 — collapsible presets and confirmed updates

- Presets start collapsed. The header keeps the saved count and + Save visible; tap the header to show or hide the cards and Browse button.
- Expanded/collapsed state survives activity recreation and switching timer tabs.
- Saving an existing name asks whether to update that preset. Matching ignores capitalization and surrounding whitespace. Confirming preserves the existing name and ID and replaces its saved configuration.
- Cancel returns to the name field without changing the existing preset, so a different name can be used. Renaming still prevents duplicate names.
- Adds native regression coverage for collapse/restore, visible Save, confirmation and cancellation, matching names, and persisted updates. The Android workflow runs core tests, lint, APK assembly, and native tests on Android 15 and 16; completed results are recorded in the PR.
