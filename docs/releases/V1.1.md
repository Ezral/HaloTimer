# HaloTimer 1.1

Android versionName 1.1.0, versionCode 9. Uses the existing development package and CI signing identity.

- Hours per track, off by default, with HH:MM:SS editors and pill digits and a centered HH / MM / SS dock. Maximum 99:59:59; seconds and minutes carry/borrow. Hours cannot be disabled while configured or running durations exceed the original limit.
- Visual HSV custom-color palette, live swatch and accessible hue, saturation and brightness sliders; optional hex entry.
- Timer-name popup with Edit / Save / Cancel, matching Morse.
- Text rotates around pill replaces the previous label.
- Completion preview wraps with explicit line spacing and animated height, including the current sequence step.
- Text motion on timer dock is an independent positive toggle. Legacy Reduce motion preferences migrate to its inverse; other animations remain enabled.
- Completion reveal contracts to its originating pill/dock on timeout or tap, including taps during expansion. Opening the menu, stopping the timer, losing overlay permission or screen-off removes the window immediately.
- Independent vibration and sound switches, including sound-only Morse. Soft 660 Hz sine pulses have 8 ms ramps and share exact pattern lengths, quiet gaps and counted/timed/until-dismiss repeats. Alarm volume and Android audio focus apply.

Saved JSON uses default values for new fields; no Room schema change or timer-data reset. Core tests cover older data, hour boundaries/limits/recovery, Morse sound samples, repeat budgets and completion reversal. Native checks cover the new settings and preview sizing.

Phone validation still needed for perceived tone level, focus behavior over other apps, audio/vibration latency and Samsung dock layout at large font scales.
